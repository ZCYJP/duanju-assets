# 短剧语法对照表 —— 参考片《看得人直呼痛快！我結清自己的餐費離開》 vs 我们的《决裂》v2

> 分析环境：h100-038（8×H100，192 核，2TB 内存）
> 参考片源：`/tmp/ref.mp4`（月華劇館，360×640 / 30fps / av1 / 1639.62s / opus 48k stereo，2026-11-12 发布，116,136 播放）
> 我们的成片：`/ssd2/duanju/drama_1min/final/drama_1min_h3.mp4`（480×832 / 24fps / 60.000s）
> **全部指标同口径、同算法、同模型测量**（场景切点均用 ffmpeg `select='gt(scene,0.2)'`；景别均用 insightface SCRFD `det_10g`，阈值与分类分档完全一致；OCR 均为 macOS Vision `VNRecognizeTextRequest`，中文+英文）

## 一、总判定：为什么"根本不是短剧"

**不是模型不行，是语法不对。** 参考片用**完全相同的 AI 生成管线**（竖屏 360×640、明显 AI 质感、真人实拍级换脸），但它有短剧的镜头语法；我们的片子是"12 张会动的 AI 立绘 + 配音"。差距集中在 4 项，全部可量化、可修复：

| 维度 | 参考片（真实短剧） | 我们 v2 | 差距倍数 |
|---|---|---|---|
| **① 镜头密度** | 717 镜 / 1639.6s = **0.437 cuts/s** | 13 镜 / 60s = **0.217 cuts/s** | **慢 2.0 倍** |
| **② 平均镜长** | **2.29s**（中位 2.17s） | **4.62s**（中位 4.92s） | **慢 2.0 倍** |
| **③ 快切镜头占比** | **76.0%** 的镜头 ≤3s | **7.7%** | **差 9.9 倍** |
| **④ 画面人物结构** | 单人 35.4% + **多人 56.1%** | **单人 98%** | **缺群戏/对话感** |

补充：**参考片 92.3% 的镜头 ≤4s，最长镜头仅 8.77s**；我们 92.3% 的镜头 ≥4s。

### 2.3 景别跳变率（剪辑感来源）

- 参考片：**相邻镜头景别切换率 64.4%**（734 个镜头中 473 次跳变）
- 最常见景别对：特写→特写 16.8%、近景→近景 11.2%、**近景→特写 9.3%**、**特写→近景 8.9%**、大特写→特写 6.1%、特写→大特写 5.3%
- 相邻 0.5s 帧的景别变化率 **25.6%**

> 参考片在"特写 ↔ 近景"之间高频来回横跳制造压迫感；我们全程一个景别，视觉上完全静止。

### 2.4 同框人数（对话感来源）

| 同框人数 | 参考片 | 我们 v2 |
|---|---|---|
| 0 人 | 8.5% | 1.7% |
| **1 人** | **35.4%** | **98.0%** |
| 2 人 | 15.3% | 0% |
| 3 人 | 13.6% | 0% |
| 4 人 | 10.5% | 0% |
| 5+ 人 | 14.8% | 0% |

- 参考片**多人帧占 56.1%**，且形成 33 个对话簇（平均 38.6s/簇，最长 270s）——连续的正反打打斗场景
- 多人帧中主角水平位置：左 1/3 **22.9%** / 中 1/3 53.9% / 右 1/3 **23.2%** → 明显的**过肩镜头 + 正反打**构图
- 多人帧景别更松（主角人脸高占比中位 **0.164**）vs 单人帧（0.226）→ 多人镜偏近景/中景以容纳两人，单人镜偏特写以强调情绪

> **这是"是短剧"与"是图片配音"最本质的差别**：短剧靠**两个人在同一空间对峙**制造冲突，我们 98% 是单人正面说话，没有对手、没有空间关系、没有"被压迫"的构图。

|---|---|---|---|

## 四、音频分层（推翻了我原先的假设）

参考片音频（48kHz 全频段）：

| 指标 | 参考片实测 | 解读 |
|---|---|---|
| 整体 RMS | **-10.70 dBFS** | 比我们 v2 的 -20.3 dBFS **响 9.6 dB** |
| 峰值 | +0.79 dBFS | 顶到 0 dBFS，短剧不留动态余量 |
| 真实数字静音占比 | **11.24%**（184.2s） | 段落之间的呼吸 |
| 低能量背景段 | 11.69%（191.7s） | — |
| 高能量段 | 77.07%（1263.6s） | 台词为主 |
| **低能量段谱平坦度** | **0.0000** | **无宽带噪声** |
| **低能量段谐波峰数** | **1 个** | **无音乐和声** |
| 低频(<200Hz)能量占比 | **0.38%** | 几乎无低频 |
| L/R 相关系数 | 0.9892 | 近单声道，Side 仅 2.16% |
| 频谱重心 | 160~640Hz 占 **65.6%**，8kHz 以上仅 0.39% | 干净的语音频谱 |
| 3s 短时响度波动 std | 44.45 dB | 段落间强对比 |

### **关键修正：参考片基本没有贯穿 BGM 床**

我最初的假设是"短剧必须有 BGM"。**实测推翻**：
- 低能量段的谱平坦度 = 0.0000（远低于 0.08 的噪声阈值）
- 显著谐波峰仅 1 个（音乐和声通常 >20）
- 安静段能量中位 -87.2 dB（相对峰值），基本是数字静音

> **所以"短剧感"不来自 BGM，来自：① 快切 ② 多人物对峙 ③ 景别横跳 ④ 强响度(比我们响 9.6dB) ⑤ 干净无噪的语音 ⑥ 双语字幕 + 多层包装。**

**这反而是好消息**：我们不需要找 BGM 素材、不需要做音乐床设计，只需要把上述 6 项做对。

### 我们 v2 的音频问题（对照）

| 问题 | 数据 | 参考片 |
|---|---|---|
| 整体太轻 | RMS -20.3 dBFS | **-10.7 dBFS**（响 9.6dB） |
| **隆隆声（脏）** | s08 有 **28.6Hz 隆隆占 35.34% 能量** | 低频<200Hz 仅 0.38% |

| 高频嘶声 | s03 区间一度 28.87% | 8kHz+ 仅 0.39% |
| 原生音轨电平跨度 | 19.4dB（s02 -14.1 ~ s03 -32.0） | 段落级动态大但干净 |
| RMS 归一副作用 | 把"又脏又响"和"干净但轻"拉平，反而抬高 s03 嘶声 | — |

## 五、叙事结构（从 39 条真实台词还原）

参考片是标准的**大女主反杀短剧**结构（27 分钟合辑 ≈ 24 集，每集约 70s）：

```
钩子(0-15s)   出院后我特意订了家高档海鲜酒楼 / 我却看到了整整两大桌生面孔
施压(15-60s)  你把名下的房和存款当嫁妆嫁过来 / 热闹点冲冲喜嘛
反套路(60s+)  楼上包间后续产生所有消费（女主提前布置规则）
铺垫(115-285s)这房子的事真能办成 / 不然早没了 / 那我就让你们占个够
围攻(320-600s) 我在医院端屎端尿伺候你 / 账单不是386,000吗
反转(600-880s) 每次不超过20分钟 / 帝王蟹两只 / 我只有8万
爽点(1020-1260)你不能真看着我被留在这里 / 求你了哪怕先批一点也行
                → 我保证让你在这座城市寸步难行
收束(1340-1620)你们不能什么都算在我头上 / 这一切都是她自己
```

**结构特征**：
1. 台词**极短**（多为 6~14 字），一镜一句
2. **每句都在推进冲突**（设局 → 反制 → 揭穿）
3. 大量**数字/金额**入戏（386,000 / 20分钟 / 帝王蟹两只 / 8万）——具体数字是短剧"真实感"的关键
4. 主角**从被动到主动**有明确翻转点（"那我就让你们占个够"）

### 我们 v2 的叙事问题

12 句台词**平铺**，无钩子、无升级、无反转点。观众看的是"12 个人轮流说一句话"，不是一场戏。

## 六、修复方案（按优先级，每项都可量化验收）

### P0 — 镜头结构重做（解决"不是短剧"的主体问题）

| 动作 | 目标值 | 手段 |
|---|---|---|
| 镜头数 13 → **26~30** | 0.44 cuts/s | 60s 内排 26~30 镜 |
| 平均镜长 4.62s → **2.1~2.3s** | 匹配参考片 | 交替 1.2s / 2.4s / 3.0s 三档 |
| ≤3s 镜头占比 7.7% → **≥75%** | 匹配参考片 | 禁止 >3.5s 的镜头 |
| 同框人数 98% 单人 → **多人帧 ≥50%** | 匹配参考片 | 反打/过肩镜位，用底图合成多人构图 |
| 景别跳变率 → **≥60%** | 匹配参考片 | 强制"特写↔近景"交替排布 |

**镜位模板（关键）**：短剧对话戏的标准剪辑是
```
A 正打(过肩，看对手肩+主角) 1.8s → B 反打(过另一侧) 1.6s
→ C 双人中景(两人同框) 2.6s → D 主角特写(情绪爆点) 1.2s
→ E 反应镜(配角表情/手部/物件特写) 1.0s → 回到 A
```
其中 **A/B 是短剧最核心的语法**——它用"镜头轴线切换"制造对话张力。

### P0 — 景别多样化

- 目标：大特写 13% / 特写 35% / 近景 28% / 中景 11% / 中全景+全景 4%
- 当前大特写+特写合计 **82.5%**，必须压到 **~48%**
- 手段：底图生成时就锁定构图（人脸占画面高 0.06~0.30 分档设计），**不用文字 prompt 描述景别**（此前实测 Z-Image 对 "extreme close-up" 响应不稳）

### P1 — 音频重做（解决杂音 + 响度）

| 问题 | 修复 |
|---|---|
| 28.6Hz 隆隆（s08） | H3 原生音轨**不用**，只取环境层；对白层用干净 TTS。整链加 **45Hz 高通** |
| 雨镜宽带噪声（s07） | 原生音轨替换为可控环境音（TTS 侧加场景音效），或强降噪 |
| 高频嘶声（s03） | 加 **低通 7.5kHz** + 分频增益；**废弃 RMS 归一**（它把嘶声抬起来了），改用固定增益表 |
| 整体太轻（-20.3dBFS） | 目标 **-16 LUFS**（GY/T 377-2023），峰值 ≤ -1 dBTP，整体 RMS 向参考片的 -10.7 dBFS 靠 |
| 参考片无 BGM | **不做 BGM 床**（这是实测结论，不要加） |

### P1 — 字幕 4 层包装（对齐参考片）

| 层 | 参考片规格 | 我们的目标 |
|---|---|---|
| 中文主字幕 | y=0.686，字高 26px/640 = 4.1% | y=0.68~0.70，字高 = 画面高 **4.1%**（480×832 → 34px） |
| 英文副字幕 | y=0.822，字高 3.8% | **新增**，y=0.82，字高 3.8%（31px），灰色 |
| 顶部信息层 | y=0.080，39/39 帧都有 | **新增**：`《决裂》` + `EP01` + 右上角角色名 |
| 底部固定层 | y=0.966，水印+AI合规声明 | 已有「本片由AI生成」，补 `纯属虚构 请勿模仿` |

另外：**去掉字幕里的"角色：xxx："前缀**（参考片 0/39 句带角色名）。

### P1 — 叙事重写

- 12 句 → **24~28 句**，每句 6~14 字，一镜一句
- 结构：钩子(3镜) → 施压(6镜) → 反制(6镜) → 反转(6镜) → 爽点(6镜)
- 引入**具体数字**（参考片 39 条台词里至少 6 条含数字）
- 设 1 个明确反转点
- 对应改底图脚本：新写 26~30 镜的底图，5 个角色多机位复用

## 七、实测方法学沉淀（可复用）

| 分析项 | 方法 | 关键参数 |
|---|---|---|
| 场景切点 | ffmpeg `select='gt(scene,0.2)',metadata=print` | 27 分钟 AV1 在 192 核上仅 18s |
| 镜头分布 | 切点时间戳 → 区间差分 | 剔除 <0.05s 碎切 |
| 景别 | insightface SCRFD `det_10g`（ONNX，CPU） | 12 进程分片，3279 帧 <5min；分档阈值 ≥0.28/0.18/0.11/0.06/0.02 |
| 同框人数 | 同帧多 bbox | 反打/过肩用主角 cx 的三分位分布判定 |
| 字幕版式 | macOS Vision `VNRecognizeTextRequest`（zh-Hans+zh-Hant+en） | 输出 y_top/y_bot/字高px/置信度/文本 |
| 音频分层 | ffmpeg → 48k f32le → numpy STFT(2048/1024) | BGM 判定：低能量段谱平坦度<0.02 且谐波峰<8 |
| 立体声宽度 | L/R 相关系数 + Side 能量占比 | 参考片 0.9892/2.16% |

**踩坑**：
- `cv2 5.0` 已移除 `CascadeClassifier`（改用 insightface SCRFD）
- 该机 `onnxruntime` 无 `CUDAExecutionProvider`，只有 CPU/Azure → 人脸检测走 CPU，**必须多进程分片**
- 远端后台任务输出被 Python 块缓冲 → 必须加 `python -u`
- macOS Vision 二进制**不能**在 Linux 远端跑 → 抽帧回本地 OCR

## 八、结论

参考片与我们用的是**同级别的 AI 生成技术**，差别全在**剪辑语法和包装**：

```
短剧感 = 快切(2.1s/镜) × 多人物对峙(56%多人帧) × 景别横跳(64%跳变)
       × 响度到位(-10.7dBFS RMS, 无噪) × 双语字幕4层包装 × 冲突递进叙事
```

我们 v2 缺的正是这六项中的六项。**重做不需要更强的模型，需要重新分镜 + 重新配音 + 重新包装。**
